# agentic-excellence

## Code review exercise

An AI agent was asked to build a product list screen with an "add to cart" action. It produced `review/ProductList.tsx`.

The team's conventions are in `AGENTS.md`.

Review the file as if it was a pull request. Talk through what you find, how serious each issue is, and how you would fix it. You can use your normal tools, including AI, but explain your thinking as you go.
